## ✨ Features

### 🎨 Background Mayhem
- **Color Picker** - Choose any color for the background (saved per site!)
- **🌈 Rainbow Party** - Endless rainbow color cycling
- **🕺 Disco Mode** - Random flashing colors like a nightclub!

### 🌀 Rotation Controls
- **Custom Rotation Slider** - Spin the page 0-360 degrees with precision
- **Quick Presets** - Instant rotation buttons: 90°, 180°, 270°, 0° (reset)
- **🌪️ SPIN IT!** - Continuous infinite spinning animation
- **💾 Auto-Save** - Your rotation settings are saved per site and persist across page reloads!

### 🎪 Chaos Modes
- **🏀 Bounce** - Make the entire page bounce up and down
- **📳 Shake** - Earthquake mode activated!
- **🔄 Flip Flop** - Watch the page flip like a pancake
- **⚡ Glitch** - Random glitchy transformations
- **🟢 Matrix Rain** - "I know Kung Fu" - Full Matrix digital rain overlay
- **🎉 Confetti** - Celebrate everything with falling confetti!

### 😂 Silly Stuff
- **🙃 Upside Down** - Turn the world upside down
- **🪞 Mirror** - Flip everything horizontally
- **🌊 Wobble** - Gentle wobbling motion
- **🔍 Crazy Zoom** - Pulsating zoom in/out

### 💥 ULTIMATE CHAOS
The combo button that does EVERYTHING AT ONCE! Rotation, scaling, color changes, confetti... pure madness!

### 💾 Persistent Settings
- Settings are automatically saved per website domain
- Your background color and rotation persist across:
  - Page refreshes
  - Navigation to different pages on the same site
  - Browser restarts
- Each website has its own independent settings!

## 🚀 Installation

### Method 1: Load Unpacked Extension (For Development)

1. Download or clone this repository to your local machine
2. Open Google Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" by toggling the switch in the top-right corner
4. Click "Load unpacked" button
5. Select the `src` folder inside `background-changer-extension`
6. The extension icon should now appear in your Chrome toolbar

### Method 2: Chrome Web Store

_This extension is currently not published on the Chrome Web Store yet._

## Usage

1. Navigate to any webpage (try it on boring news sites or your company's homepage 😈)
2. Click the WEB CHAOS MAKER extension icon
3. Choose your chaos:

### Basic Controls
- **Color Picker** - Select a color and click "Apply Color" - it saves automatically!
- **Rotation Presets** - Quick buttons for 90°, 180°, 270° rotation
- **Custom Rotation** - Use the slider for any angle you want

### Settings Persistence
- Your settings are **automatically saved per website**
- Navigate to different pages on the same site? Settings stay!
- Close and reopen your browser? Settings are still there!
- Each domain (google.com, youtube.com, etc.) has its own settings

### For Temporary Fun
- Fun modes (Rainbow, Disco, Spin, etc.) are temporary
- They don't save - refresh to clear them
- Perfect for quick laughs without permanent changes

### For Maximum Chaos
- Hit **🕺 Disco Mode** for a rave
- Try **🌪️ SPIN IT** to make everyone dizzy
- Go **🟢 Matrix Rain** for that hacker aesthetic
- **💥 ULTIMATE CHAOS** button = ALL THE THINGS AT ONCE

### Reset
- Click **🛑 STOP THE MADNESS** to clear everything and reset saved settings
